Performance plan

Know which blok broke it.

Performance adds the tools that test, measure and share a prompt. Every one of them works on the bloks you already have, so nothing changes about how you write.

P01 Performance

A red cell that points at a line.

Every check comes from a blok. When a check fails, 41prompts traces the failure back to the blok most likely to have caused it, with a confidence score, on each model separately.

  • Failures attributed per model, not per prompt
  • Click a failure to jump to the blok
  • Checks that could not be graded are reported as that, never as a pass

Questions

Before you paste anything.

Is my prompt private?

Yes. Every prompt and version is visible only to you. Nothing becomes public unless you create a share page, which needs Performance, and you can take that page down at any time.

What do you do with my API keys?

They run your prompts on the provider you choose and nothing else. Keys are encrypted at rest, shown once when you save them, and never written to logs. The provider bills your own account.

What is free, exactly?

Everything you need to write, save, version, run once and copy a prompt, with no limits on prompts, bloks or versions. Testing, analysis, comparison and sharing are in Performance.

What happens if I cancel Performance?

You keep every prompt, blok and version on Free. Performance tools lock again, and test results you already ran stay readable.

What is a blok?

One typed part of a prompt: context, constraint, example or expects. Each blok owns an exact span of the compiled prompt. Expects bloks describe what a good answer does, and never appear in the prompt itself.
